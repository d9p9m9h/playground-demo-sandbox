# Playground Demo Sandbox

This repository contains a standalone demo of the original playground sandbox extracted from the learning repo.

## Features
- Simple React playground editor
- Compile endpoint using Sucrase
- Sandboxed preview iframe
- Theme toggle
- Secure script escaping for HTML injection prevention in the sandbox

## Run locally

```bash
npm install
npm run dev
```

Open http://127.0.0.1:3000

## Notes
This copy was extracted from the original project and hardened before being used as a standalone demo app.
